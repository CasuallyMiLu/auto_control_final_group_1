# data/

`video_tracks/`：2026-11-09 拍的 6 支場景影片（攝影機距牆 450 cm、高 130 cm、有放大、轉 90° 裝）逐幀追蹤結果。
影片本身太大（共 1 GB）沒放進 repo，放在組內雲端。

| 影片 | 場景 | 內容 |
|---|---|---|
| WIN_20261109_19_49_31_Pro | 方形 | 無人機繞方形（3558 幀，18.5 fps） |
| WIN_20261109_19_55_46_Pro | 圓形 | 無人機大多不在畫面內 |
| WIN_20261109_19_57_36_Pro | 圓形 | 無人機繞圓（**偵測模型驗證用，沒參與訓練**） |
| WIN_20261109_20_08_23_Pro | 主題 2 | 短片段（**驗證用**） |
| WIN_20261109_20_10_01_Pro | 主題 2 | 循跡 + 雷射 |
| WIN_20261109_20_13_14_Pro | 主題 2 | 只有雷射點、沒有無人機（訓練用負樣本） |

- `*_bsm.csv`：背景相減追蹤；`*_yolo.csv`：微調後 YOLO26 追蹤。欄位：`frame, t, u, v`（像素，原點左上）、`X, Y`（牆面 cm，自動校正）、
  `lu, lv, lX, lY`（雷射點）、`conf, ms`、`bx0..by1`（框）。由 `tools/test_vision_video.py` 產生。
- `*_yolo_vs_path.png`：圓形影片的無人機軌跡 vs 自動抓到的白色中心線（中位距離 6.3 cm），`tools/video_track_error.py` 產生。
